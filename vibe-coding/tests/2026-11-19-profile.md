# profile 模組測試情境

- 建立日期：2026-11-19
- 對應任務：[M1 T6](../milestones/M1-account-foundation.md)
- 測試程式：`packages/fitness/profile/tests/`
- 備註：使用者要求 M1 一路做完，情境未逐條事先確認，寫完後請使用者事後檢視增減。

## Unit（`tests/Unit`）

- P-U01/test_bmr_for_male_uses_mifflin_st_jeor：男性 BMR = 10×體重 + 6.25×身高 − 5×年齡 + 5，四捨五入。
- P-U02/test_bmr_for_female_uses_mifflin_st_jeor：女性常數項為 −161。
- P-U03/test_lose_goal_subtracts_daily_deficit：減脂每週 0.5 kg → 每日 −550 kcal，日常消耗 = BMR × 活動係數，蛋白質 = 體重 × 1.8。
- P-U04/test_maintain_goal_has_no_adjustment：維持目標不加減熱量，蛋白質係數 1.2。
- P-U05/test_gain_goal_adds_daily_surplus：增肌每週 0.25 kg → 每日 +275 kcal，蛋白質係數 1.6。
- P-U06/test_bmr_override_takes_precedence：有實測 BMR 時以實測值計算，仍回傳公式值供比較。
- P-U07/test_below_floor_depends_on_gender_floor：熱量目標低於 男 1500／女 1200 時 below_floor 為 true，等於下限時為 false。

## Feature（`tests/Feature`）

### 首次設定
- P-F01/test_not_onboarded_user_is_redirected_to_onboarding：未完成設定進入今日頁會被導向 `/onboarding`。
- P-F02/test_not_onboarded_user_can_reach_excepted_routes：未完成設定仍可進入設定頁與登出。
- P-F03/test_onboarded_user_visiting_onboarding_is_redirected_to_today：已完成設定再進首次設定頁會回今日頁。
- P-F04/test_onboarding_page_provides_options_and_calculation：首次設定頁帶入選項（含說明）、計算係數與使用者時區的今天。
- P-F05/test_completing_onboarding_saves_profile_and_first_weight_log：送出後寫入個人資料、第一筆體重、標記完成並導向今日頁。
- P-F06/test_onboarding_requires_all_fields：缺欄位時回傳各欄位錯誤，不標記完成。
- P-F07/test_onboarding_rejects_out_of_range_values：未滿 13 歲、身高／體重超出範圍、減脂速度超過 1.0、BMR 實測值超出 500～5000 都被拒絕。
- P-F08/test_maintain_goal_stores_null_rate：維持目標即使送了速度也存成 null。

### 我的與編輯個人資料
- P-F09/test_me_page_shows_profile_targets_and_current_weight：「我的」頁帶入個人資料、每日目標（含熱量下限欄位）、目前體重與較前次差值。
- P-F10/test_edit_page_renders_profile_and_options：編輯頁帶入個人資料、目前體重、今天與選項。
- P-F11/test_profile_can_be_updated：修改個人資料後導回「我的」，BMR 實測值與速度正確儲存。
- P-F12/test_profile_update_validates_values：速度超出目標範圍、BMR 實測值不是整數時被拒絕。

### 體重紀錄
- P-F13/test_weight_logs_are_listed_newest_first_with_deltas：列表依量測日新到舊，同日依建立順序，附較前一筆差值與總筆數。
- P-F14/test_weight_logs_load_more_by_page：`?page=2` 顯示前兩批，`has_more` 正確。
- P-F15/test_weight_log_can_be_recorded_and_defaults_to_today：新增紀錄，未給日期時用使用者時區的今天。
- P-F16/test_weight_log_rejects_future_date_and_out_of_range_weight：未來日期、超出 20～300 kg 被拒絕。
- P-F17/test_user_can_delete_own_weight_log：有兩筆以上時可刪除自己的紀錄。
- P-F18/test_last_weight_log_cannot_be_deleted：只剩一筆時刪除失敗並回傳錯誤訊息。
- P-F19/test_user_cannot_delete_other_users_weight_log：刪除別人的紀錄回 404，資料不變。
- P-F20/test_guests_are_redirected_from_profile_routes：未登入存取 profile 路由導向登入頁。
