說明

  • 「Google 回應」模擬從 Google 回到網站時的結果：授權成功／這個 Google 帳號已被其他帳號連結（只影響連結）／使用者按取消（或 state 不符）。登入時是否成功看「連結狀態」。
  • 登入頁：Google 帳號已連結 → 進今日頁（未完成首次設定的照樣導向首次設定）；未連結 → 頁內錯誤提示；不會建立帳號、不會用 email 自動綁定。
  • 用 Google 登入一律「記住我」，帳密登入仍依勾選。
  • 成功結果（已連結、已解除連結）用既有的 Toast；失敗結果用頁內錯誤提示，不會自動消失，方便看完較長的說明。
  • 「Google 設定：未設定」表示 .env 沒有 GOOGLE_CLIENT_ID：登入頁不顯示 Google 按鈕，已連結帳號頁顯示「目前沒有可連結的服務」。
  • Google 頭像只在已連結帳號頁顯示（demo 以字母圓圈代替實際照片），不當站內大頭貼。
  • 設定頁的分頁與標題沿用 starter kit 的 settings Layout：手機在上方、寬度 1024px 以上改到左側。
