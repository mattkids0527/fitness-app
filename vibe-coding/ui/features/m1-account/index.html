說明

  • 品牌色：橘（hsl 21 90% 48%，對應 Tailwind orange-600）。
  • 每日熱量目標低於男 1,500／女 1,200 kcal 時顯示提醒（只提醒、不阻擋儲存）。
  • 數值皆以後端設定計算：活動係數 1.2／1.3／1.4／1.5、每公斤 7700 kcal、蛋白質 1.8／1.2／1.6 g/kg、減脂 0.1～1.0、增肌 0.1～0.5 kg/週。
  • 「首次設定」完成前看不到底部 Tab 與側欄（middleware 會擋），完成後進入「今日」。
  • 飲食、健身、＋選單中尚未實作的功能顯示「即將推出」。
  • 手機與桌機是同一份畫面，以寬度 768px 切換：手機底部 Tab、桌機側欄；底部面板在桌機變成置中對話框。
