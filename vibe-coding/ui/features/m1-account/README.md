# M1 帳號基礎 畫面

- 確認日期：2026-11-19
- 對應任務：[M1 帳號基礎 T4](../../../milestones/M1-account-foundation.md)
- 開啟方式：瀏覽器打開 `index.html`，上方工具列可切換畫面、手機／桌機、淺色／深色
- 定案設計：
  - 品牌色：橘 `hsl(21 90% 48%)`（Tailwind orange-600），淺底 `hsl(33 100% 96%)`；其餘沿用 shadcn-vue token
  - 熱量下限提醒：每日熱量目標低於 男 1,500／女 1,200 kcal 時顯示黃色提醒，只提醒、不阻擋儲存
  - 版面以寬度 768px 切換：手機底部 Tab、桌機側欄；底部面板在桌機變成置中對話框
  - 編輯個人資料為獨立頁面（T5 需新增 `GET /me/edit` 路由）
  - 刪除體重紀錄：垃圾桶按鈕 + 確認對話框；只剩一筆時停用並說明原因

## 畫面情境

- m1-01/onboarding_basic：首次設定步驟 1，填性別、出生日期、身高，未填按下一步顯示欄位錯誤
- m1-02/onboarding_weight_activity：步驟 2，填目前體重（成為第一筆體重紀錄）與日常活動量（註明不含運動）
- m1-03/onboarding_goal：步驟 3，選減脂／維持／增肌，非維持時以滑桿選每週速度並即時顯示每日熱量增減
- m1-04/onboarding_confirm：步驟 4，BMR 小工具（公式計算／填入實測值）與每日目標拆解，按完成設定進入今日
- m1-05/layout_mobile_tabbar：手機底部 Tab（今日／飲食／＋／健身／我的），首次設定完成前不顯示
- m1-06/layout_desktop_sidebar：桌機側欄（快速新增、今日、飲食、健身、我的），飲食與健身標示即將推出
- m1-07/today：今日頁，熱量環形圖（剩餘熱量）、蛋白質還差多少、記錄體重入口，餐點／喝水／運動為即將推出
- m1-08/coming_soon：飲食、健身 Tab 的即將推出佔位頁，列出之後的功能
- m1-09/quick_add_sheet：＋選單，M1 只有記錄體重可用，其他四項標示即將推出
- m1-10/me：我的頁，每日目標（可展開計算方式）、最新體重與較前次增減、個人資料列表、設定列表
- m1-11/profile_edit：編輯個人資料，含 BMR 小工具與儲存前的每日目標即時預覽
- m1-12/low_calorie_warning：每日熱量目標低於建議下限時，在首次設定、編輯頁、我的頁顯示提醒
- m1-13/weight_logs：體重紀錄頁，新增表單（體重＋日期，預設今天）與歷史列表（每筆附較前次增減）
- m1-14/weight_add_sheet：記錄體重底部面板，從今日、我的、＋選單開啟
- m1-15/weight_delete_confirm：刪除體重確認對話框；刪除最新一筆時提示目前體重與目標會重算；只剩一筆時不能刪
- m1-16/appearance_sheet：外觀面板，淺色／深色／跟隨系統
- m1-17/dark_mode：所有畫面的深色版本
