# M5 健身紀錄 畫面

- 確認日期：2026-11-21
- 依據規格：[M5 規格](../../../specs/2026-11-21-m5-exercise.md)
- 開啟方式：瀏覽器打開 `index.html`。上半部「流程試玩」可以操作（數字可實際輸入，消耗熱量即時計算；新增的紀錄、分類、項目會留在頁面上，「從頭開始」重置）；工具列切換淺色／深色、手機／桌機、照片辨識結果、今天剩餘次數。下半部「畫面一覽」是每個狀態的靜態畫面。
- 範例資料：目前體重 70 kg（11/20 記錄，11/17 是 70.6 kg），每日熱量目標 2,000 kcal；「現在」是 2026/11/21 19:42。今天有室外跑步、槓鈴臥推、槓鈴划船三筆；11/19 有一筆已封存的「飛輪」；11/18 有一筆槓鈴肩推（用來看「帶入上次紀錄」）。

## 定案設計（demo 確認，2026-11-21；以下為規格沒寫、依 demo 定案的做法）

1. **封存項目可以還原**：管理頁最下面「已封存（N）」收合區，可以把項目還原；原分類已刪除時放回同記錄方式的第一個分類。規格 Q3 只寫封存，沒寫還原。
2. **紀錄選單「再做一次（帶入今天）」**：比照飲食頁「再吃一次」，帶入同樣的組數或時長到今天的記錄頁。封存項目不顯示這個選項。
3. **運動加的喝水量四捨五入到 10 ml**：今天運動 42.9 分鐘 × 500 ml／小時 = 357.5 → 顯示 360 ml。
4. **照片辨識的提示詞帶入使用者現有的分類與項目名稱**：AI 判斷是同一個動作時直接用現有名稱，畫面才會出現「已有這個項目」（m5-23 第三張）。
5. **候選卡建議的分類**：同名且同記錄方式的現有分類 → 「放進『重訓』」；沒有 → 「新建分類『核心』」；表單的分類下拉只列同記錄方式的分類。
6. **填時長的快選**：15／30／45／60 分。
7. **選擇項目面板「最近做過」最多 5 個**，依最後一次紀錄時間排序。
8. **記錄頁的計算依據**寫在表單下方（體重與日期、MET、逐組的秒數與休息），編輯舊紀錄另註明「以紀錄日的體重重新計算」。
9. **今日頁卡片順序**：手機為熱量 → 餐點 → 運動 → 喝水 → 體重；桌機左欄熱量、餐點、運動，右欄喝水、體重。原本的「即將推出：運動」拿掉。

## 畫面情境

- m5-01/workouts：健身頁，日期切換、當日消耗／時間／訓練量、「分類與項目」入口、紀錄依時間排序（填時長顯示時長與距離，逐組顯示組數摘要）
- m5-02/workouts_empty：健身頁空狀態，過去日期顯示「回到今天」，「新增運動」
- m5-03/quick_add：＋選單「健身」改成可用，點了開選擇項目面板
- m5-04/picker：選擇項目面板，搜尋、拍照辨識／上傳照片辨識、最近做過、依分類分組（標記錄方式）、管理入口
- m5-05/picker_not_found：搜尋不到時「新增項目『搜尋字』」，存檔後直接進記錄頁
- m5-06/log_duration：記錄填時長，時長必填（快選）、距離選填只記錄、即時預估消耗
- m5-07/log_sets_start：記錄逐組剛進來，「上次」卡一鍵帶入，預設一組空白
- m5-08/log_sets_filled：逐組填好，「新增一組」「複製上一組」，即時預估消耗、訓練量、估算時間，最多 20 組
- m5-09/log_edit：編輯舊紀錄，右上刪除，以快照與紀錄日體重重算，封存項目仍可編輯
- m5-10/log_menu：紀錄選單，編輯、再做一次（帶入今天）、刪除
- m5-11/log_delete：刪除紀錄確認
- m5-12/manage：分類與項目管理，分類標記錄方式與項目數，項目列 MET（逐組另列秒數），新增分類，已封存可還原
- m5-13/category_new：新增分類，名稱＋記錄方式，提醒建立後不能改
- m5-14/category_menu：分類選單，改名、往上移、往下移、刪除（改名時記錄方式鎖住）
- m5-15/category_delete_blocked：分類還有項目不能刪除
- m5-16/exercise_new：新增項目（填時長），MET 附參考值，即時「每 30 分鐘約 X kcal」
- m5-17/exercise_edit：編輯項目（逐組），只能移到同記錄方式分類，每下秒數、組間休息，「3 組 × 10 下約 X kcal」，底部封存
- m5-18/exercise_archive：封存確認（有紀錄）；沒有紀錄時為刪除確認
- m5-19/identify：照片辨識頁（沿用 M4 分析頁），補充說明、今天剩餘次數（每天 10 次）
- m5-20/identifying：辨識中，掃描動畫、可取消
- m5-21/identify_not_exercise：看不出器材或動作，主按鈕「重拍／換一張」；其他錯誤為「重新辨識」
- m5-22/identify_limit：今天次數用完，只能手動新增項目
- m5-23/candidates：辨識結果候選卡（最多 3 個），器材、說明、記錄方式、MET、秒數、信心度、放進哪個分類；「已有這個項目」直接記錄
- m5-24/candidates_new_category：建議的分類不存在時標「新建分類」
- m5-25/identify_form：帶入新增項目表單，標示來自照片辨識，分類預設新建、可改選同記錄方式的現有分類，存檔後進記錄頁
- m5-26/today：今日頁，熱量剩餘加回運動並標「含運動 +N kcal」，「今日運動」卡，喝水建議量拆成體重＋運動
- m5-27/water_sheet：喝水面板說明列加上運動時數，建議量拆解
- m5-28/desktop_workouts：桌機健身頁，左合計與入口、右紀錄列表
- m5-29/desktop_picker：桌機選擇項目（置中對話框，只有上傳照片辨識）
- m5-30/desktop_log_sets：桌機記錄逐組
- m5-31/desktop_manage：桌機分類與項目
- m5-32/desktop_today：桌機今日頁
