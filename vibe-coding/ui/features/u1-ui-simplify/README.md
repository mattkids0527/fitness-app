# U1 介面精簡 畫面

- 確認日期：2026-11-20
- 對應任務：[U1 介面精簡 T1](../../../milestones/U1-ui-simplify.md)
- 依據規格：[U1 規格](../../../specs/2026-11-20-u1-ui-simplify.md)
- 開啟方式：瀏覽器打開 `index.html`，每個主題左右對照「原本」與「改後」；上方工具列可切換淺色／深色、只看改後
- 定案設計：
  - 營養素固定圖示與顏色（lucide）：蛋白質 `Drumstick`／rose、碳水 `Wheat`／amber、脂肪 `Nut`／violet、纖維 `Leaf`／emerald；淺色用 -500、深色用 -400 色階
  - 營養素出現在格子裡用「圖示＋數值＋小字」，在列表裡用「圖示＋數值」，在表單標籤用「圖示＋文字」
  - 表單拿掉「（選填）」，改成必填欄位打橘色 `*`
  - 只有圖示的按鈕一律加 `aria-label`
  - 底部 Tab 文字、kcal／g 單位、確認類按鈕（儲存、刪除）的文字保留

## 畫面情境

- u1-01/zoom_lock：點兩下、兩指縮放（Android 與 iPhone）都不會放大頁面
- u1-02/nutrient_grid：營養素四格改成彩色圖示＋數值，下方小字標籤
- u1-03/form_labels：餐點項目與常用食物表單的熱量／營養素標籤前加圖示；拿掉「（選填）」，名稱、熱量打 `*`；「備註」同規則
- u1-04/today_calorie_card：今日熱量卡「熱量目標」「已攝取」改成靶心與餐具圖示；蛋白質列用雞腿圖示與蛋白質色進度條，「還差 N g」改成「−N g」，達成時顯示 ✓
- u1-05/today_meals_card：今日餐點列拿掉餐別文字，只留餐別圖示與時間；右上「飲食頁 ›」改成圓形箭頭按鈕
- u1-06/today_water_card：喝水卡右上「紀錄 ›」改成圓形箭頭按鈕
- u1-07/quick_add：＋選單拿掉說明與小字，改三欄大圖示；可用的（記錄餐點、喝水、體重）在前，即將推出的淡化並加時鐘標記；「手動記錄」改名「記錄餐點」
- u1-08/meal_card：飲食頁餐點卡拿掉「· N 個項目」
- u1-09/saved_foods_info：常用食物頁說明框改成頁首 ⓘ，點了才顯示；副標只留「N 項」
- u1-10/food_list_macros：常用食物列表與快速帶入清單的營養素改成彩色小圖示＋數值；「最近使用：」改成時鐘圖示
