說明

  • demo 的「現在」固定為 2026-11-20（五）12:40；熱量目標 1,678 kcal、蛋白質目標 141 g、體重 78.5 kg，沿用 M1 demo 的範例使用者。
  • 今日頁的熱量卡沿用 M1 的環形圖，已攝取熱量與蛋白質改為實際加總；超過目標時環形圖變紅並顯示「超過 N kcal」。碳水、脂肪、纖維的目標與達成率留給 M6。
  • 餐別依時間預設：5–10 點早餐、10–14 點午餐、17–21 點晚餐，其餘點心；手動選過餐別後，改時間不再自動切換。
  • 食物項目只有名稱、熱量必填；營養素留空表示「不知道」，加總時當 0，並提示「部分項目沒有填營養素」（纖維不列入提示）。
  • 快速帶入：常用食物、最近吃過（近 30 天、20 筆）點選後選份數 ×0.5／×1／×1.5／×2；複製整餐（近 14 天）直接加入該餐所有項目。
  • 項目旁的 ☆ 把項目加入常用食物（同名不能重複）；熱量沒填但有蛋白質／碳水／脂肪時，出現「依營養素估算」按鈕。
  • 「再吃一次」開新增頁，日期為今天、餐別沿用，內容預填，按儲存才建立。
  • 喝水只能記今天；今日頁 +250／+500 直接記錄並顯示 toast，按錯從喝水面板刪除。建議量 = 體重 × 35 ml，四捨五入到 50 ml。
  • 「我的」「記錄體重」是 M1 已完成的畫面，demo 中略過；健身維持即將推出。
