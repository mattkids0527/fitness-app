# M3 飲食紀錄＋喝水 畫面

- 確認日期：2026-11-20
- 對應任務：[M3 飲食紀錄＋喝水 T1](../../../milestones/M3-meal-water.md)
- 依據規格：[M3 規格](../../../specs/2026-11-20-m3-meal-water.md)
- 開啟方式：瀏覽器打開 `index.html`，上方工具列可切換畫面、資料情境（一般／今天空白／超標＋缺營養素）、手機／桌機、淺色／深色
- 定案設計：
  - 今日頁熱量卡沿用 M1 的環形圖，已攝取熱量與蛋白質改為實際加總；超過目標時環形圖與已攝取變紅，中央顯示「超過 N kcal」
  - 缺營養素提示用黃色提醒框（蛋白質／碳水／脂肪任一未填時），纖維不列入
  - 喝水用藍色（`hsl(199 89% 48%)`）區分，其餘沿用橘色品牌色
  - 餐點卡片點本身進入編輯，「⋯」打開選單（編輯、再吃一次、刪除）
  - 新增餐點頁手機由上到下：基本資料 → 快速帶入 → 項目清單 → 備註，底部固定「本餐合計＋儲存」；桌機左右兩欄
  - 刪除確認一律用底部面板（桌機置中對話框），沿用 M1 體重刪除的做法

## 畫面情境

- m3-01/today_calorie_card：今日頁熱量卡，環形圖顯示剩餘熱量，已攝取與蛋白質為實際加總、蛋白質還差 N g
- m3-02/today_calorie_over：攝取超過目標時環形圖變紅，顯示「超過 N kcal」
- m3-03/today_meals_card：今日餐點簡表，依時間列出餐別、時間、項目名稱、熱量，點擊進入編輯；沒有紀錄時顯示提示與「記錄餐點」
- m3-04/today_water_card：今日喝水卡，已喝／建議量、還差 N ml、進度條，+250／+500 直接記錄並顯示 toast
- m3-05/meals_index：飲食頁，日期切換（不能到未來、非今天時顯示「回到今天」）、當日合計（熱量、蛋白質、碳水、脂肪、纖維）、常用食物入口
- m3-06/meals_groups：依早餐／午餐／晚餐／點心分組，餐別旁顯示小計與「新增」，沒有紀錄的餐別顯示「＋ 新增早餐」
- m3-07/meals_missing_nutrients：當日有項目缺蛋白質／碳水／脂肪時，合計卡顯示黃色提醒
- m3-08/meal_actions_sheet：餐點選單（編輯、再吃一次、刪除）
- m3-09/meal_delete_confirm：刪除餐點確認，顯示日期時間、項目數與熱量
- m3-10/meal_form_basic：新增餐點頁基本資料，日期（不能未來）、時間（今天預設現在、其他日期預設餐別代表時間）、餐別依時間自動選擇
- m3-11/meal_form_pick_saved：快速帶入「常用食物」分頁，依最近使用排序，點選後選份數
- m3-12/meal_form_pick_recent：快速帶入「最近吃過」分頁，近 30 天依名稱取最近一次、最多 20 筆
- m3-13/meal_form_copy_meal：快速帶入「複製整餐」分頁，近 14 天的餐點，點選後加入該餐所有項目
- m3-14/servings_sheet：選份數面板 ×0.5／×1／×1.5／×2，即時顯示換算後的熱量與營養素
- m3-15/meal_form_items：項目清單，收合時顯示名稱、份量、營養素摘要、熱量、☆；展開可編輯所有欄位、刪除
- m3-16/meal_form_estimate：熱量沒填但有蛋白質／碳水／脂肪時，顯示「依營養素估算 N kcal」按鈕
- m3-17/meal_form_star：項目旁 ☆ 加入常用食物，已在常用食物時為實心；沒填名稱或熱量時提示
- m3-18/meal_form_validation：儲存時至少一個項目、名稱與熱量必填，錯誤的項目自動展開
- m3-19/meal_form_again：「再吃一次」開新增頁，日期今天、餐別沿用、內容預填，上方提示按儲存才建立
- m3-20/meal_form_edit：編輯餐點，右上角刪除
- m3-21/saved_foods：常用食物管理頁，依最近使用排序，顯示每份營養素與最近使用日期
- m3-22/saved_food_sheet：新增／編輯常用食物面板，同名時拒絕儲存；編輯時可刪除（確認後刪除，不影響已記錄的餐點）
- m3-23/water_sheet：喝水面板，進度、+250／+500、自訂（10～2000 ml）、今天的紀錄可刪除
- m3-24/quick_add_sheet：＋選單的「手動記錄」「喝水」改為可用，拍照分析、健身維持即將推出
- m3-25/desktop_layout：桌機版飲食頁（合計｜分組）與新增餐點頁（基本資料＋帶入｜項目）左右兩欄
- m3-26/dark_mode：所有畫面的深色版本
